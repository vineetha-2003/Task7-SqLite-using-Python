# Task7-SqLite-using-Python

# Objective
To perform a basic sales analysis using SQL within Python by:
- Storing sales data in a SQLite database
- Calculating total quantity sold and total revenue by product category
- Visualizing the revenue using a bar chart

# Dataset Used
- File: `sales_data.csv`
- Key Columns: `Product_Category`, `Quantity_Sold`, `Sales_Amount`

# Tools & Libraries
- Python
- SQLite3
- Pandas
- Matplotlib
- Google Colab (for execution)

# Steps Performed

1. Uploaded the `sales_data.csv` file into Google Colab
2. Loaded the dataset using `pandas`
3. Stored the dataset in a SQLite database (`sales_data_task7.db`)
4. Wrote and executed an SQL query to calculate:
   - Total quantity sold per product category
   - Total revenue per product category
5. Printed the result table
6. Plotted a bar chart to show total revenue by category


## ✅ Result Summary
The SQL query successfully aggregated the data, and the bar chart gave a clear visual of which product categories generated the highest revenue.
